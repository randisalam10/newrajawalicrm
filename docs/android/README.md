# 📱 Dokumentasi Mobile Android (RajawaliApp)

Folder ini berisi referensi teknis dan spesifikasi API untuk pengembangan aplikasi Android **PT Rajawali Mix** (`RajawaliApp`).

### Dokumen Utama:
- 📘 [**API_DOCUMENTATION.md**](./API_DOCUMENTATION.md) — Panduan Lengkap REST API Android:
  - Format Autentikasi JWT Bearer (Token 30 Hari).
  - Lifecycle State Machine Approval PO (**`DRAFT`**, **`SUBMITTED`**, **`APPROVED`**, **`REJECTED`**).
  - Endpoint PO, Upload Tanda Tangan Canvas Base64, Executive Dashboard, dan Kas Lapangan (RBL).
  - Contoh Kode Kotlin, Retrofit Interface, AuthInterceptor, dan Data Classes.
- 📋 [**FITUR_IMPLEMENTASI_ANDROID.md**](../FITUR_IMPLEMENTASI_ANDROID.md) — Dokumen Spesifikasi Kebutuhan & Roadmap Fitur Android (Batching, Driver Retase, Logistik, RBL).
